# Keystone Valley FCU: fake bank back office

A deliberately hostile, 2008-style credit union back office. It is the test target for **intyy**, a
computer-use automation system. It is hostile, not broken: a human operator can complete every flow.

- **`Bank App Design.md`** is the full design, and the source of truth for what gets built.
- **`CONTRACT.md`** is the only file the intyy side may read. Keep intyy-specific knowledge out of
  everything else. Never document screens, labels, routes, or business-rule thresholds there.

## Quick start

```
cp .env.example .env        # fill in the six credential variables
make up                     # bank app on 127.0.0.1:8081 (internal) + chaos proxy on 127.0.0.1:8080
open http://127.0.0.1:8080/login.do
```

Requires [`uv`](https://docs.astral.sh/uv/). It installs Python 3.12 and the locked dependencies itself.

| Target | What it does |
|---|---|
| `make up` | Builds the seed if needed, generates `KVFCU_PROXY_SECRET` if unset, runs both processes. Ctrl-C stops both. |
| `make seed` | Rebuilds `var/seed.db` from `seed/seed.py` and copies it to `var/live.db`. |
| `make reset` | Copies `var/seed.db` over `var/live.db`: seed data, no sessions. Works without test mode. |
| `make test` | Runs the pytest suite (about 3 s). |

## How it fits together

```
browser / intyy -> chaos proxy :8080 (chaos/proxy.py, aiohttp) -> bank app :8081 (bank/app.py, Flask) -> var/live.db
```

- **No bypass.** The proxy adds `X-KVFCU-Proxy: $KVFCU_PROXY_SECRET` to every forwarded request. The app
  answers anything without it with a plain 403. The proxy strips any `X-KVFCU-*` header a client sends,
  so proxy-only signals can't be forged.
- **Determinism.** `chaos/proxy.py:decide()` is a pure function of seed, entropy, named faults, route
  key, and per-route counter. Everything random-looking comes from `h()`, a SHA-256 of those inputs.
- **Test endpoints.** The proxy handles `chaos`, `faults`, and `faultlog` itself. It forwards `reset`
  (after clearing its own counters, faults, and log), `clock`, and `oracle` to the app.
- **Sessions.** Server-side, stored in SQLite in `live.db`, cookie `JSESSIONID`, 5 minutes idle in
  real time. Reset replaces the file, so it logs everyone out.
- **Back/Refresh detection.** Main-frame pages bump a per-session page counter, embedded in forms as
  `pageSeq`. Non-confirm POSTs with a stale value show "Page Expired". The two confirm POSTs deliberately
  don't check it: a refresh re-submits and creates a second account.
- **Supervisor pop-up.** On approval, the pop-up re-submits a hidden `reloadForm` in its opener. This
  avoids the browser's "resubmit form?" prompt, and it doesn't bump the page counter.
- **Variants.** `bank/brands.py` holds per-tenant labels, palette, branch codes, and column order.
  The proxy's fault pages use the same table.

## Environment variables

User-facing options are in `CONTRACT.md` section 4. Development only:

| Variable | Default | Use |
|---|---|---|
| `KVFCU_VAR_DIR` | `var` | Where `seed.db`, `live.db`, and `fault_log.jsonl` live. The tests use temporary directories. |
| `KVFCU_APP_PORT` / `KVFCU_PROXY_PORT` | `8081` / `8080` | Lets the tests run their own stack alongside a running `make up`. |
| `KVFCU_PROXY_SECRET` | generated by `make up` | Shared secret between proxy and app. The app refuses to start without it. |

## Layout

```
bank/app.py        all routes, sessions, business rules, app-side test endpoints
bank/brands.py     tenant table (keystone, lakeshore)
bank/templates/    Jinja pages (nested tables, frames, 2008 styling)
bank/static/       CSS per tenant, SVG logos, blinking NEW!, strip-mode button images (bx1-3.svg)
chaos/proxy.py     the chaos proxy
seed/seed.py       schema + deterministic seed data (member categories are listed in CONTRACT.md)
tests/             pytest; test_proxy.py runs the real app + proxy as subprocesses
```

`bank/static/bx*.svg` draw their labels as pixel rectangles, not `<text>`, so strip mode leaks no button
text even from the image files.

## Tests

`make test` runs 67 tests. The six required by the design (section 17):

| Requirement | Test |
|---|---|
| Same seed and entropy give an identical fault log | `test_proxy.py::test_same_seed_and_entropy_give_identical_fault_log` |
| Each named fault triggers on the right route and count | `test_proxy.py::test_every_named_kind_fires_on_its_route_and_count_only` |
| After-endpoint block commits but drops the reply | `test_proxy.py::test_drop_after_confirm_commits_but_drops_reply` |
| Reset restores seed data exactly | `test_proxy.py::test_reset_through_proxy_restores_seed_exactly`, `test_seed.py::test_make_reset_restores_seed_exactly` |
| Test endpoints return 404 when test mode is off | `test_proxy.py::test_test_endpoints_404_when_test_mode_off`, `test_endpoints.py::test_endpoints_404_when_test_mode_off` |
| No proxy header gets 403 from the app | `test_bank.py::test_no_proxy_header_is_403`, `test_proxy.py::test_pass_through_adds_secret_and_strips_client_headers` |

`test_bank.py`, `test_accounts.py`, and `test_supervisor.py` drive the app in-process through Flask's
test client, with the secret header set. `test_decide.py` unit-tests the proxy's decision logic.
